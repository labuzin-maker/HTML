# RedNote 轮播图 (carousel)

6-слайдовая карусель для поста в 小红书 (RedNote/Xiaohongshu) — тот же контент, что и на `../index.html`, но в виде картинок 1080×1440 (формат 3:4, стандартный для RedNote), потому что **обычный пост на этой платформе не позволяет вставить кликабельную внешнюю ссылку** — вместо этого последний слайд несёт два сканируемых QR-кода.

## Слайды

1. Хук (заголовок + подзаголовок + иллюстрация)
2. Что такое QR-меню
3. Как найти заведения на карте
4. 3 шага использования
5. Контекст (почему это появилось)
6. **Финал: два QR-кода** — левый ведёт на `https://concierge-vl.ru/start` (эта же страница в браузере, полная версия текста), правый — на `https://concierge-vl.ru/map` (напрямую на карту).

## Как пересобрать

```bash
pip install qrcode[pil]
python3 gen_qr.py        # генерирует qr-start.png и qr-map.png (888×888, высокая коррекция ошибок H)
python3 build_slides.py  # собирает slide1.html … slide6.html (встраивает QR как base64)
npm i -g playwright       # если ещё не установлен глобально
node render.js            # рендерит slide1.png … slide6.png через headless Chromium (1080×1440, retina 2x)
```

Чтобы поменять текст или цвета — правь содержимое слайдов в `build_slides.py` (блок с `page(...)` на каждый слайд) и перезапускай оба шага.

## Зачем не закоммичены сами картинки

`.png`-файлы (и slide*.html/qr-*.png как промежуточные артефакты) не коммитились в этот репозиторий — готовые PNG были отправлены пользователю напрямую. При необходимости просто запусти скрипты заново по инструкции выше.
