# concierge-vl-start

Мобильный лендинг на китайском языке (`/start`) для проекта **宾至指南** (concierge-vl.ru) — объясняет гостям из Китая, как пользоваться QR-меню с ИИ-помощником в кафе и ресторанах Владивостока, и ведёт на публичную карту [concierge-vl.ru/map](https://concierge-vl.ru/map).

## Что это

Одна самодостаточная HTML-страница (`index.html`), без сборки и внешних зависимостей — чтобы быстро грузилась во встроенном браузере RedNote (小红书) на мобильных.

Контент написан в тоне личной рекомендации от путешественника, а не рекламы: короткий эмоциональный хук → объяснение, что такое QR-меню → как найти нужные заведения на карте → призыв к действию → мягкое объяснение контекста (рост китайского турпотока во Владивостоке).

## Структура

- `index.html` — вся страница: разметка, стили (`<style>` в `<head>`), инлайн SVG-иллюстрации. JS не используется.

## Особенности реализации

- **Mobile-first**: одна колонка, `max-width: 480px`, крупный шрифт (17px), большие CTA-кнопки.
- **Без внешних зависимостей**: ни шрифтов, ни библиотек — только системные шрифты (`PingFang SC`, `Microsoft YaHei` и т.д.) для быстрой загрузки.
- **Иллюстрации вместо фото**: сейчас используются лёгкие инлайн-SVG (миска с едой, сканирование QR, карта с пином) в тёплой палитре — это временная замена живым фотографиям. Рекомендуется заменить их на реальные фото еды/города Владивостока при наличии (см. классы `.hero-art` и `.art`).
- **Повторяющийся CTA**: кнопка-ссылка на `https://concierge-vl.ru/map` встречается 4 раза по мере скролла.
- **Подсказка про встроенный браузер**: под кнопками карты — ненавязчивая заметка о том, что в браузере RedNote может не работать построение маршрута, с инструкцией открыть в системном браузере.
- **Без хардкода заведений**: список мест нигде не перечисляется текстом — весь трафик по заведениям идёт через карту, чтобы не дублировать и не рассинхронизировать данные.

## Деплой

Файл `index.html` предполагается разместить по пути `/start` на `concierge-vl.ru` (например, как статический файл за реверс-прокси/CDN или в соответствующем роуте текущего бэкенда сайта). Правка контента — прямое редактирование текста в `index.html`.
