# RedNote карусель — Побутчики

6-слайдовая карусель для поста в 5c0f红书 (RedNote) про сервис поиска попутчиков. Сделана по той же схеме, что и `../../concierge-vl-start/carousel` (тот же визуальный язык, тот же аккаунт „宾至指南“ и аудитория) — на последнем слайде два сканируемых QR-кода.

## Слайды

1. Хук: „один еду — дорого“
2. Что это (как работает автоматический мэтчинг по дате/маршруту)
3. Как пользоваться (3 шага)
4. Почему это выгодно (экономия на трансфере)
5. Самое важное: это не официальная служба, безопасность на свой страх — честное упоминание, а не обещание безоговорочной безопасности
6. **Финал: два QR-кода** — левый ведёт на главную страницу (форма подачи заявки), правый — на `/requests` (публичный список уже поданных заявок, без контактов) — чтобы человек сначала мог проверить, есть ли уже кто-то на его маршруте, прежде чем самому подавать заявку.

## Как пересобрать

```bash
pip install qrcode[pil]
python3 gen_qr.py        # qr-submit.png и qr-list.png (высокая коррекция ошибок H)
python3 build_slides.py  # slide1.html … slide6.html (встраивает QR как base64)
npm i -g playwright       # если ещё не установлен глобально
node render.js            # slide1.png … slide6.png через headless Chromium (1080×1440, retina 2x)
```

Готовые PNG не закоммичены в репозиторий (бинарный контент не переживает текстовый commit API GitHub) — они отправлены пользователю напрямую.

## Если сменится домен Railway

`gen_qr.py` сейчас зашит URL авто-сгенерированный домен `html-production-a794.up.railway.app`. Если подключите свой домен или домен изменится — правьте два URL в `gen_qr.py` и пересоберите карусель заново.
